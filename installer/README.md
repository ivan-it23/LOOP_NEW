# Установщик приложения "Кольца"

Установщик собирается через Inno Setup 6 из Release-папки WinUI-приложения. Последний собранный и проверенный поставочный артефакт имеет версию `1.0.6`.

Текущий исходный код в `HEAD f62ab67a` содержит более новые функции кольца: программный сдвиг ёмкостей для 3/4 Tx, чтение/запись сигнатуры через диалекты `SGN` и `SG`, статусные панели кольца и команду `ZERASE`. Метаданные проекта пока также имеют номер `1.0.6`, но новый Release/Inno Setup после этих изменений не зафиксирован как собранный. Перед следующей публикацией необходимо повысить номер версии выше `1.0.6`.

## Сборка

1. Опубликовать приложение:

```powershell
dotnet build LOOP_NEXT.sln -c Release -p:Platform=x64 --no-restore
```

2. Собрать установщик:

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\setup.iss
```

Готовый файл появится в `installer\Output\Koltsa-Setup-<version>.exe`.

Папка `installer\Output` является локальным релизным выводом и игнорируется git. Готовый `.exe` нужно загружать на хостинг или прикладывать к релизу вручную.

## Исторически проверенный релиз 1.0.6

Локальный комплект выпуска:

```text
installer\Output\Koltsa-Setup-1.0.6.exe
installer\Output\Koltsa-Setup-1.0.6.exe.sha256
installer\Output\koltsa-version.txt
```

Проверенные метаданные:

- версия приложения: `1.0.6.0`;
- версия установщика: `1.0.6`;
- размер установщика: `62088594` байт;
- SHA-256: `95870CB2E9DDCEDD598434C7BDADC256EFC77C84EDF5B127B820D91DE371BDE8`;
- Release x64: `0` предупреждений, `0` ошибок;
- protocol checks: `18/18 passed`;
- smoke-запуск: окно `Кольца` создано и отвечало системе.

Сценарий `[Files]` исключает из поставки `LoopDeviceLog.txt`, `*.log`, `*.tmp` и `*.pdb`. Runtime-журнал испытаний из `src\LoopDeviceLog.txt` не должен попадать пользователям.

Показатели `18/18` и приведённая контрольная сумма относятся именно к этому уже собранному артефакту. Текущий исходный код после последующих изменений отдельно проверен в `Debug|x64` без предупреждений и ошибок, а набор автономных проверок расширен до `32/32`, включая проверки структуры и формул Excel-рапорта; эти результаты нельзя приписывать старому установщику без новой Release-сборки.

## Автообновление

Приложение проверяет обновления при запуске по адресу:

```text
http://ivanbohg.beget.tech/FilesForProgramVisualisation/koltsa-version.txt
```

Формат `koltsa-version.txt`:

```text
1.0.6
Koltsa-Setup-1.0.6.exe
```

В репозитории поддерживается готовый файл `installer\koltsa-version.txt` для последнего поставочного номера. При выпуске новой версии его нужно обновлять синхронно с `LOOP.Next.App.csproj` и `installer\setup.iss`.

Установщик из второй строки должен лежать в той же папке:

```text
http://ivanbohg.beget.tech/FilesForProgramVisualisation/Koltsa-Setup-1.0.6.exe
```

Если версия на сервере выше текущей версии приложения, пользователь получает предложение скачать и установить обновление. Обновление запускается через скачанный Inno Setup установщик, чтобы обновлялись не только `Кольца.exe`, но и все DLL, ресурсы WinUI и ассеты приложения.

## Чек-лист публикации

1. Выбрать номер выше `1.0.6` и синхронно изменить его в `LOOP.Next.App.csproj`, `setup.iss` и `koltsa-version.txt`.
2. Выполнить актуальные protocol checks и получить полный успешный результат (сейчас `32/32`).
3. Собрать Release x64 и Inno Setup установщик; проверить отсутствие предупреждений и ошибок.
4. Проверить запуск установленного приложения и аппаратный smoke-тест с исправным кольцом: подключение, чтение сигнатуры по Bluetooth, чтение параметров и начало штатного workflow. `ZERASE` не включать в обязательный smoke-тест, поскольку это разрушающая параметры диагностическая команда.
5. Проверить имя, версию, размер и SHA-256 нового файла.
6. Загрузить `Koltsa-Setup-<new-version>.exe` в `FilesForProgramVisualisation`.
7. После установщика загрузить актуальный `koltsa-version.txt` в ту же папку.
8. Проверить прямую доступность обоих URL.
9. Запустить установленную предыдущую версию и убедиться, что она предлагает обновление до нового номера.

На 2026-07-23 локально проверен исторический установщик `1.0.6`; его загрузка на сервер и живая проверка автообновления не подтверждены. После последних функций кольца новый поставочный установщик ещё не задокументирован как собранный.
