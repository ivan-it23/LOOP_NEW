# Установщик приложения "Кольца"

Установщик собирается через Inno Setup 6 из Release-папки WinUI-приложения. Последний собранный поставочный артефакт имеет версию `1.1.1`.

Версия `1.1.1` собрана из актуального рабочего дерева. В неё входят принудительная светлая тема и стабильные корпоративные цвета элементов управления, пользовательский масштаб окна, подсветка активных состояний прибора, кольца и воздуха, видимые границы кнопок R1-R8, четыре знака после запятой для расчётной реактивности, уточнённая документация по усреднению и сокращённая активная подпись кнопки `Воздух: Задан`. Более ранние локальные артефакты остаются в `installer\Output` как история сборок.

## Сборка

1. Опубликовать приложение:

```powershell
dotnet build LOOP_NEXT.sln -c Release -p:Platform=x64 --no-restore
```

2. Собрать установщик:

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\setup.iss
```

Готовый файл появится в `installer\Output\Koltsa-Setup-<version>.exe`.

Папка `installer\Output` является локальным релизным выводом и игнорируется git. Готовый `.exe` нужно загружать на хостинг или прикладывать к релизу вручную.

Сценарий `[Files]` исключает из поставки `LoopDeviceLog.txt`, `*.log`, `*.tmp` и `*.pdb`. Runtime-журнал испытаний из `src\LoopDeviceLog.txt` не должен попадать пользователям.

## Автообновление

Приложение проверяет обновления при запуске по адресу:

```text
http://ivanbohg.beget.tech/FilesForProgramVisualisation/koltsa-version.txt
```

Формат `koltsa-version.txt`:

```text
1.1.1
Koltsa-Setup-1.1.1.exe
```

В репозитории поддерживается готовый файл `installer\koltsa-version.txt` для последнего поставочного номера. При выпуске новой версии его нужно обновлять синхронно с `LOOP.Next.App.csproj` и `installer\setup.iss`.

Установщик из второй строки должен лежать в той же папке:

```text
http://ivanbohg.beget.tech/FilesForProgramVisualisation/Koltsa-Setup-1.1.1.exe
```

Если версия на сервере выше текущей версии приложения, пользователь получает предложение скачать и установить обновление. Обновление запускается через скачанный Inno Setup установщик, чтобы обновлялись не только `Кольца.exe`, но и все DLL, ресурсы WinUI и ассеты приложения.

## Чек-лист публикации

1. Выбрать номер выше последнего опубликованного и синхронно изменить его в `LOOP.Next.App.csproj`, `setup.iss` и `koltsa-version.txt`.
2. Выполнить актуальные protocol checks и получить полный успешный результат (сейчас `35/35`).
3. Собрать Release x64 и Inno Setup установщик; проверить отсутствие предупреждений и ошибок.
4. Проверить запуск установленного приложения и аппаратный smoke-тест с исправным кольцом: подключение, чтение сигнатуры по Bluetooth, чтение параметров и начало штатного workflow. `ZERASE` не включать в обязательный smoke-тест, поскольку это разрушающая параметры диагностическая команда.
5. Проверить имя, версию, размер и SHA-256 нового файла.
6. Загрузить `Koltsa-Setup-<new-version>.exe` в `FilesForProgramVisualisation`.
7. После установщика загрузить актуальный `koltsa-version.txt` в ту же папку.
8. Проверить прямую доступность обоих URL.
9. Запустить установленную предыдущую версию и убедиться, что она предлагает обновление до нового номера.

На 2026-08-04 локально собран установщик `1.1.1`. Его загрузка на сервер и живая проверка автообновления не подтверждены: пока `Koltsa-Setup-1.1.1.exe` и обновлённый `koltsa-version.txt` не лежат в `FilesForProgramVisualisation`, у пользователей обновление не появится.
